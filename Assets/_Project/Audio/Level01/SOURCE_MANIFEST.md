# Level 01 Audio — REVIEW

This folder contains the lightweight Level 1 review mix. It is not an Art Lock and remains subject to the user's listening review inside Unity.

| Cue | Production file | Source role |
|---|---|---|
| Broadside cannon | `L01_SFX_Broadside_Cannon_R3.ogg` | Cannon fire with restrained hull and low-frequency support |
| Gate energy | `L01_SFX_Gate_EnergyLoop_R1.wav` | Continuous blue portal/energy bed |
| Gate ×4 | `L01_SFX_Gate_MultiplyX4_R1.ogg` | Four rising multiplication pulses |
| Gate damage | `L01_SFX_Gate_Damage_R1.ogg` | Descending energy break with a restrained stone impact |
| Shallow-water landing | `L01_SFX_Landing_ShallowWater_R1.ogg` | Water displacement with wooden hull contact |
| Crew loss | `L01_SFX_Crew_Loss_R1.ogg` | Muffled deck impact and short overboard splash |
| Guardian armor hit | `L01_SFX_Guardian_ArmorHit_R1.ogg` | Heavy metal impact with body weight |
| Guardian defeat | `L01_SFX_Guardian_Defeat_R1.ogg` | Armor, masonry, collapse and restrained rumble |
| Corsair reward | `L01_SFX_Reward_Corsair_R1.ogg` | Short fretless victory/reward phrase |
| Failure | `L01_SFX_Failure_Medieval_R1.mp3` | Restrained medieval defeat phrase |
| Sea ambience | `L01_AMB_SeaLoop_R1.ogg` | Seam-crossfaded coastal wave loop |
| Wind ambience | `L01_AMB_WindLoop_R1.wav` | Light maritime wind loop |
| Traversal music | `L01_MUS_Traversal_Pirate_R1.mp3` | Compact pirate traversal theme |
| Guardian battle music | `L01_MUS_GuardianBattle_R1.mp3` | Full battle score, streamed in Unity |

Editable/downloaded sources are stored under `ArtSource/Audio/Incoming/OpenGameArt/Level01/`. The deterministic local build is `tools/build_level01_audio.py`. Source URLs and license records are in `THIRD_PARTY_NOTICES.md`.
